# B-021: Sök och filtrera i inköpslistan

- **Status:** Idé
- **Typ:** Funktion
- **Prioritet:** –
- **Skapad:** 2026-10-01

## User story
Som resenär vill jag kunna söka och filtrera i inköpslistan så att jag snabbt
hittar det jag letar efter.

## Acceptanskriterier
- [ ] Fritextsökning på namn.
- [ ] Filtrering på tagg.
- [ ] Namn- och taggfilter kan kombineras.
